# ---------------------------------------------------------------------------
# GPU vs CPU -- READ THIS if the compute indicator stays RED on Windows:
#
# Native-Windows TensorFlow is CPU-ONLY from 2.11 onward. Google dropped
# Windows GPU support after TF 2.10, so `tensorflow>=2.16` (what this file
# installs) will NEVER touch your GPU on Windows -- no config fixes that.
# Confirm with:  python scripts/gpu_check.py
#
# This LSTM is TINY (a few hundred numbers), so CPU trains it in seconds and
# GPU would give basically zero speedup. Red/CPU is totally fine here.
#
# If you still want GPU (e.g. for learning), realistic options:
#   (A) WSL2 + NVIDIA CUDA (NVIDIA GPUs only):
#         pip install "tensorflow[and-cuda]>=2.16"
#   (B) Old DirectML path (any DX12 GPU, but frozen at TF 2.10, Python <=3.10):
#         pip install tensorflow-cpu==2.10.0 tensorflow-directml-plugin
#   (C) PyTorch + DirectML (any DX12 GPU on Windows) -- different framework,
#         would require porting the model to PyTorch:
#         pip install torch-directml
# ---------------------------------------------------------------------------
